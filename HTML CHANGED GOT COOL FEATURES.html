How to use the tracker:

  1. Load footage via the + Load Footage button
  2. Click Auto Track — the system finds high-contrast features and tracks them through the clip
  3. When done, click Solve + Add to Scene — a camera object appears animated to match
  4. For a ground plane: select 4 trackers that lie on a flat surface, then click Floor — it places those 4 points at Y=0 world origin
