Product Overview

Phnt3D Studio is a fully browser-based 3D modeling environment. It requires no installation — open the HTML file and start building. The app is built around a central viewport, a left tool strip, top dropdown menus, and a right Object Manager panel.

Fast Primitive Creation

One-click spawning of 8 primitive shapes directly into the viewport.

Immediate Transform Workflows

Move, Rotate, Scale tools available instantly with keyboard shortcuts.

Node-Based Management

Object Manager provides a node canvas for scene organisation, grouping and connections.

Project Save / Open

Full project serialisation to .p3ds files including camera, selection and node layout.

OBJ Import / Export

Bring in external models and export finished work in OBJ format.

Keyboard-Driven Speed

Nearly every tool is accessible by a single key for uninterrupted modeling.

File / Data Workflows

Save Project

Serialises the full scene to a .p3ds JSON file — shapes, transforms, camera, tool state, selection and Object Manager layout.

File › Save

Open Project

Loads a .p3ds file. Prompts before overwriting the current scene, then fully reconstructs all state.

File › Open

Import OBJ

Parses .obj geometry, builds a model group, adds edge lines, uses app-consistent gray material, selects imported object and pushes an undo entry.

File › Import

Export

Exports to OBJ via browser Blob URL. Includes a Selected Only option. Additional export formats may be added in future builds.

File › Export

Shape Creation System

4.1 Available Primitives

Click the Shapes button to open the panel and spawn any of the 8 primitives:

Cube
Plane
Cylinder
Sphere
Cone
Torus
Pyramid
Disc

4.2 Spawn Characteristics

  • New shapes are created as grouped objects containing a mesh and a LineSegments outline for edge visibility.
  • Default material is a consistent gray modeling look applied to all primitives.
  • Plane and Disc are spawned as flat-oriented surfaces; Torus and Pyramid have orientation corrections applied for visual consistency.
  • Spawned shape is immediately available for selection and transforms.
  • An Object Manager node is created and linked automatically for every spawned object.

Transform Tooling

Move Tool

Translates selected object(s) along constrained axes via a gizmo. A move indicator box is displayed during drag. Action recorded for undo on mouse-up.

M

Rotate Tool

Rotates selected object(s) via axis rings. Displays a live degree indicator. Supports smooth long-rotation with cumulative angle behaviour.

R

Scale Tool

Scales selected object(s) using a gizmo. Switches into scale transform mode and updates gizmo state accordingly.

S

All Tools

Combined editing mode for faster workflows — Move, Rotate and Scale available at once. Tool button visuals update to reflect the combined state.

A
Tool Exclusivity: Rotate and Scale modes are managed as toggles. Activating one mode can disable exclusive alternatives. All Tools mode has its own independent toggle logic.

Selection System

6.1 Click Selection

Single click on a viewport object selects it. Clicking empty space deselects the current selection.

6.2 Multi-Selection

Shift + Click toggles an object's membership in the current selection, supporting additive or subtractive workflows.

6.3 Box Selection Blocker

Box-Selection BlockerToggle on/off via Space or button

Quickly enables or disables viewport box-selection behaviour. Button highlight reflects the current state.

6.4 Delete

Delete key removes selected shapes. If an Object Manager group container is selected, the container is removed first.

6.5 Selection / Transform Coupling

Selection changes automatically recalculate gizmo visibility. Outline colours and selected states are kept in sync with the current selection array at all times.

Clipboard & History

Copy

Copies selected shapes or selected group container payload. Captures enough data for full paste reconstruction.

Ctrl + C

Cut

Copies then removes selected shapes. The clipboard is cleared after paste (true cut semantics).

Ctrl + X

Paste

Pastes shape or group container payloads. Pasted items are selected immediately and added to the undo stack.

Ctrl + V

Undo

Steps back through an action stack covering Add, Remove, Move, Rotate, Scale, Join, and group container operations.

Ctrl + Z

Redo

Reapplies undone actions. Two shortcut variants are supported.

Ctrl + Y Ctrl + Shift + Z

Advanced Object Actions

8.1 Group Objects

Group ObjectsCreates an Object Manager group container from the current selection

Uses the current selection to create a group container in the Object Manager. The container can hold and represent grouped members in the node workspace. Group container operations are fully undoable.

8.2 Join Objects

Join ObjectsRequires 2+ selected objects

Merges selected geometry into one combined mesh/group. Removes original shapes and inserts the joined result. Rebuilds selection to the newly joined object. The join operation is tracked for undo/redo.

8.3 Focus On Object

Focus On ObjectF key or button

Animates the camera to focus on the selected target(s). Essential for quickly recentering the view within large or complex scenes.

Object Manager (Node Workspace)

11.1 What it is

A node-based control panel for scene objects. Sits on the right side of the app. It is a first-class workflow area — not just a scene list — supporting connections, grouping, and hierarchy operations.

11.2 Node Features

  • One node per object in the scene
  • Node labels with type display
  • Drag to reposition nodes freely in the manager canvas
  • Inline rename flow for node titles

11.3 Box Select in Manager

Drag-select multiple nodes directly inside the manager canvas. Hold Shift for additive selection. Selection is synchronised bi-directionally with the viewport.

11.4 Group Containers

Visual grouping rectangles with a title and colour controls. Can be selected, moved, and resized. All container operations support full undo/redo.

11.5 Connection Systems

The manager supports multiple connection/state categories:

  • Visibility-related links
  • Parent / child hierarchy links
  • Port-based connections
  • Editor connections
  • Connect / disconnect operations with undo/redo

11.6 Visibility Node

Press Tab while hovering the Object Manager area. If a visibility node does not yet exist, the app creates one automatically.

11.7 Manager Persistence

The full manager layout and node state is saved to and loaded from .p3ds project files.

Interaction Rules & Conditions

Many shortcuts are intentionally context-sensitive to prevent accidental actions:

Input Field Guard

Tool shortcuts (M, R, S, A, V, Space, F) are ignored while any input, textarea or contenteditable element has focus — so typing object names won't accidentally switch tools.

Viewport Hover Requirement

Several shortcuts only fire when the mouse cursor is inside the viewport area, preventing unintended activations while interacting with panels or menus.

UI Overlap Checks

Logic prevents accidental tool activation when the cursor is positioned over menus, dropdowns, or toolbar buttons.

Separate Interaction Zones

Viewport interactions (gizmos, click-select, camera) and Object Manager interactions (node drag, box-select, rename) are handled by separate logic contexts that don't interfere with each other.
